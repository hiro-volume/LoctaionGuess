# LocationGuess

ストリートビューの景色を見て、地図上で場所を当てるゲームです。
提出すると、正解から何 m 離れていたかと得点が表示されます。

- 出題範囲: **シンガポール / 広島県 / 広島市中心部**、または**自分で作った範囲**（円・多角形）
- 1ラウンド最大1000点。範囲が狭いほど、距離による減点が厳しくなります
- 「移動あり」にすると、ストリートビューの中を歩けます

## 無料枠で遊ぶための仕組み

| 使うもの | 課金のされ方 | Google の無料枠（月） | このアプリでの消費 |
|---|---|---|---|
| Dynamic Street View | パノラマを1回作るごとに1回 | 5,000回 | 1ラウンドにつき1回 |
| Dynamic Maps | 地図を1回作るごとに1回 | 10,000回 | ページを開くたびに1回 |
| Street View Metadata（場所探し） | **課金なし** | 無制限 | 1ラウンドに数回〜数十回 |

つまり、5ラウンドのゲームなら **月に約1,000ゲームまで無料**です。

二重のガードで無料枠を超えないようにしています。

1. **アプリ側の上限**（`config.js` の `limits`）: 月4,000ラウンド / 地図8,000回に達すると、ゲームを始められなくなります。
   ※ このブラウザの中だけで数えています。別のブラウザや PC で遊んだぶんは合算されません。
2. **Google Cloud のクォータ**（下の手順 5）: Google 側で止まるので、こちらが本当の安全装置です。**必ず設定してください。**

## セットアップ手順

### 1. Google Cloud のプロジェクトを作る
1. https://console.cloud.google.com/ を開く
2. 上部のプロジェクト選択 →「新しいプロジェクト」→ 名前は `LocationGuess` など
3. 請求先アカウントを紐づける（クレジットカードの登録が必要です。無料枠の範囲なら請求は $0）

### 2. API を有効にする
「APIとサービス」→「ライブラリ」で、次の2つを有効にします。
- **Maps JavaScript API**（地図とストリートビュー）
- **Street View Static API**（場所探しのメタデータで使います。画像は取得しません）
- **Maps Static API**（自作の範囲のサムネイル画像に使います。無料枠 10,000回/月。有効にしなくてもゲームは動き、サムネイルが線画になるだけです）

### 3. APIキーを作る
「APIとサービス」→「認証情報」→「認証情報を作成」→「APIキー」

### 4. APIキーに制限をかける（重要）
作ったキーの編集画面で設定します。
- **アプリケーションの制限**: 「ウェブサイト」→ `http://localhost:8000/*` を追加
- **API の制限**: 「キーを制限」→ Maps JavaScript API、Street View Static API、Maps Static API だけにチェック

これで、キーを他人に見られても、他のサイトから使われることはありません。

### 5. クォータ（1日の上限）を確認する
「Google Maps Platform」→「割り当て」→ API で **Maps JavaScript API** を選ぶと、上限の一覧が出ます。

- **Map loads per day**（地図の読み込み）: 変更できる場合は **300**（10,000 ÷ 31 ≒ 322）にします。
- **ストリートビュー（パノラマ）用の1日の上限は、この一覧にありません**（2026年11月時点）。
  そのため、ストリートビューの課金を Google 側で止める設定はできません。

代わりに、次の守りで無料枠を超えないようにしています。
- **APIキーの制限**（手順4）: `localhost` 以外からは使えないので、使えるのは自分だけです。
- **アプリ側の上限**（`config.js`）: 月4,000ラウンドで止まります。
- **無料トライアル中**は、有料アカウントにアップグレードしない限り請求されません。
- アップグレードしたあとは、手順6の予算アラートを必ず設定してください。

### 6. 予算アラートを設定する（おすすめ）
「お支払い」→「予算とアラート」で、予算 **¥100** などの小さな額を作ります。
もし課金が発生したらすぐメールが来ます（通知だけで、課金は止まりません）。

### 7. キーを貼って起動する
1. `config.js` を開き、`apiKey: "YOUR_API_KEY"` の部分に作ったキーを貼る
2. このフォルダでローカルサーバーを起動する

   ```bash
   python -m http.server 8000
   ```

3. ブラウザで http://localhost:8000 を開く

※ `index.html` をダブルクリックして直接開く（file://）と、キーの制限に引っかかって動きません。

## 友達と遊ぶ（マルチプレイ）

「ゲームを始める」→「マルチプレイ」で部屋を作ると、**ルームコード・招待リンク・QRコード**が出ます。
友達がリンクを開くか、「遊び方を選ぶ」画面でルームコードを入力すると参加できます。
全員が名前を決めて「決定」を押すと、ホスト（部屋を作った人）がマップ選択に進めます。

### 仕組み
- 部屋を作った人のブラウザが「部屋」になり、参加者はそこに直接つながります（WebRTC / [PeerJS](https://peerjs.com/)）。自分でサーバーを用意する必要はありません。
- つなぐ最初の手続きだけ、PeerJS の無料の公開サーバーを使います。ゲーム中のやりとりはブラウザどうしで直接行います。
- 出題地点はホストが決めて、全員に同じ景色を出します。正解の位置は、ラウンドが終わるまで参加者には送りません。
- 会社や学校のネットワーク、一部のスマホ回線では、つながらないことがあります。

### 友達にゲームを開いてもらう方法
`http://localhost:8000` は**自分のPCでしか開けません**。どちらかの方法で、友達が開けるアドレスを用意してください。

**A. 同じ Wi‑Fi にいる友達と遊ぶ（いちばん簡単）**
1. PC の IP アドレスを調べる（PowerShell で `ipconfig` →「IPv4 アドレス」。例: `192.168.1.23`）
2. いつもどおり `python -m http.server 8000` で起動する（Windows のファイアウォールの確認が出たら「許可」）
3. Google Cloud の APIキーの「ウェブサイトの制限」に `http://192.168.1.23:8000/*` を追加する
4. **ホストも** `http://192.168.1.23:8000` で開いてから部屋を作る（招待リンクがこのアドレスになります）

**B. 離れた場所の友達と遊ぶ**
このフォルダを GitHub Pages や Netlify などで公開し、そのアドレス（例: `https://あなたの名前.github.io/*`）を APIキーの「ウェブサイトの制限」に追加してください。
APIキーはページの中に入るので誰でも見られますが、ウェブサイトの制限をかけておけば、他のサイトでは使えません。

### 料金について（大事）
- 参加者のブラウザも、**ホストと同じ APIキー**でストリートビューを読み込みます。
  4人で5ラウンド遊ぶと、ストリートビューは 4 × 5 = 20回です。無料枠（月5,000回）なら、4人で約250ゲームまでです。
- アプリ側の上限（`config.js`）は、それぞれのブラウザで別々に数えています。人数が多いときは、Google Cloud の予算アラートで全体の使用量を見てください。

## 使用量モニター（自分のPC専用）

ゲーム画面の「今月の無料枠」は、そのブラウザで数えた回数です（マルチプレイでは、自分が開いた部屋の参加者の分も足されます）。
友達がひとりで遊んだ分なども含めた**APIキー全体の正確な回数**は、Google Cloud の記録を読む「使用量モニター」で確認できます。
モニターは自分のPC（`127.0.0.1`）でだけ動き、他の人からは開けません。

### 準備（最初の1回だけ）
1. 必要な部品を入れる
   ```bash
   pip install google-auth requests
   ```
2. 読み取り専用のサービスアカウントを作る
   1. Google Cloud の「IAM と管理」→「サービス アカウント」→「サービス アカウントを作成」
   2. 名前は `usage-monitor` など。ロールは **「モニタリング閲覧者」**（Monitoring Viewer）だけを付ける
   3. 作ったアカウントを開き、「鍵」→「鍵を追加」→「新しい鍵を作成」→ **JSON** を選ぶと、ファイルがダウンロードされる
3. ダウンロードしたファイルを `monitor/service-account.json` という名前で置く
   - このファイルは**絶対に人に渡したり公開したりしないでください**（`.gitignore` で GitHub には上がらないようにしてあります）

### 起動
```bash
python monitor/monitor.py
```
ブラウザで http://127.0.0.1:8765 が開き、ストリートビュー・地図・範囲の地図画像ごとの回数と、無料枠までの残りが表示されます。止めるときは Ctrl+C です。

- Google の記録は数分遅れて反映されます。表示は5分ごとに自動で更新されます
- 無料枠は**太平洋時間の月ごと**なので、日本時間では毎月1日の夕方に切り替わります
- 認証なしで見た目だけ確かめるときは `python monitor/monitor.py --demo`

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` / `style.css` | 画面 |
| `app.js` | ゲームの処理（場所探し、距離計算、得点、範囲エディタ、使用量カウンタ） |
| `multiplayer.js` | マルチプレイ（部屋づくり、ロビー、ラウンドの同期、結果） |
| `monitor/` | 使用量モニター（自分のPCで動かす。`service-account.json` は公開しない） |
| `config.js` | APIキーとアプリ側の上限 |
| `regions.js` | 出題範囲のプリセット |
| `hiroshima-boundary.js` | 広島県の境界データ（[dataofjapan/land](https://github.com/dataofjapan/land) を簡略化） |
| `world-boundary.js` / `region-boundary.js` | プレイ記録の世界地図に使う国・州/県の境界（[Natural Earth](https://www.naturalearthdata.com/)、パブリックドメイン） |

自作の範囲・設定・使用量は、ブラウザの localStorage に保存されます。
